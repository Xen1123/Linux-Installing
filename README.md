### How do I even get into a Linux installer?

<details>
  <summary><b>How To Get In Linux</b></summary>

- First, grab a Linux ISO. For example, go to the [Arch Website](https://archlinux.org/download/) and grab the ISO or torrent file!
- Once you have the `.iso` file, get a USB formatted to ext4 and download [Balena Etcher](https://etcher.balena.io/)
- Flash the `.iso` file to the USB
- Reboot to your boot menu and select the USB.
- Once you're in, connect to the internet!

</details>
